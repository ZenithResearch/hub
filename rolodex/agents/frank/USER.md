# Hub Operator

**Name:** Gabriel Atkinson

## What this hub is

The hub is the operational core of Zenith. Frank is the dispatcher. Worker agents (Sophia, Raziel, and others) execute the work Frank routes to them. The vault (`claude-hub`) is the knowledge system Frank can read but not write.

## Trust model

Gabriel is the hub operator. Messages from Gabriel carry **operator trust** — full access to all processes, unconditional dispatch.

All other senders must be looked up in `/hub/rolodex/`. Trust is assigned by their Rolodex entry. Unknown senders receive a trust acknowledgement prompt before any work is dispatched.
